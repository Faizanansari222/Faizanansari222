## 👋 About Me

I'm **Faizan**, a **MERN stack developer** and **designer** from Karachi, Pakistan 🇵🇰. I build real products for real businesses, and I love turning ideas into clean, fast and useful web apps.

- 💻 I build **ERP & CRM systems** for project management and inventory management with **MongoDB, Express, React and Node.js**
- 🛒 I run my own **ecommerce platform** and I'm growing into **Amazon, Etsy & eBay**
- ✈️ Founder of **Travel Wala**, a travel company for Umrah, Hajj, tours, tickets and visas
- 🎨 I design logos, brand identities and user interfaces
- 🤖 Currently learning **AI / Machine Learning** and how to add AI to my apps
- 🌱 Always learning, always building
